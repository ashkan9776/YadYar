# یادیار (Yadyar) 🧠

**اپ هوشمند یادگیری با تکرار فاصله‌دار (Spaced Repetition) — آفلاین، فارسی، راست‌به‌چپ.**

یادیار یک اپلیکیشن فلش‌کارت برای زبان‌آموزان و دانشجویان فارسی‌زبانه که با الگوریتم **SM-2** (همان الگوریتم Anki) زمان مرور هر کارت را طوری تنظیم می‌کند که درست قبل از فراموش‌شدن، آن را به یادت بیاورد. همه‌چیز روی دستگاه ذخیره می‌شود و بدون اینترنت کار می‌کند.

> ساخته‌شده با Flutter — تم تاریک/روشن، تقویم شمسی، و رابط کاربری کاملاً فارسی.

---

## ✨ ویژگی‌ها

### یادگیری
- 🔁 **تکرار فاصله‌دار (SM-2):** زمان‌بندی هوشمند مرور بر اساس کیفیت پاسخ (سخت / خوب / آسون).
- 🃏 **دک‌ها و کارت‌ها:** ساخت، ویرایش و حذف دک و کارت با پشتیبانی از سه دک آماده (کنکور ریاضی، لغات IELTS، آزمون استخدامی).
- 🎯 **آزمون چندگزینه‌ای:** آزمون خودسنجی چهارگزینه‌ای از روی کارت‌های هر دک، با امتیاز و نتیجه.
- ⌨️ **حالت تایپ جواب:** جواب را تایپ کن و خودکار (با اغماض از غلط املایی جزئی) بررسی شود.
- 🎯 **مرور نقاط ضعف:** کارت‌هایی که زیاد «سخت» می‌زنی خودکار در یک نشست جمع می‌شوند.
- ↩️ **بازگشت (Undo):** لغو آخرین ارزیابی در حین مرور.

### انگیزه و پیگیری
- 🏆 **گیمیفیکیشن:** XP، سطح‌بندی و ۱۰ نشانِ دستاورد (استریک، تعداد مرور، دقت و…).
- 🔥 **استریک روزانه** و **هدف روزانه‌ی قابل‌تنظیم** با نوار پیشرفت.
- 📊 **آمار کامل:** نقشه‌ی حرارتی فعالیت (سبک گیت‌هاب)، پیش‌بینی کارت‌های سررسید ۷ روز آینده، و توزیع دقت.
- 🔔 **یادآوری دقیق:** نوتیفیکیشن روزانه سرِ ساعت + یادآوری هوشمندِ شبانه وقتی استریکت در خطره.

### تجربه‌ی کاربری
- 🌗 **تم روشن/تاریک** با امکان تعویض زنده (و حالت سیستم).
- 🔊 **تلفظ صوتی (TTS):** خواندن کلمه/جواب با تشخیص خودکار زبان (انگلیسی/فارسی).
- ➗ **رندر فرمول ریاضی (LaTeX):** نوشتن فرمول بین `$...$` و نمایش واقعی آن.
- 🎉 **افکت‌های حرفه‌ای:** انیمیشن کاغذرنگی هنگام موفقیت + لرزش لمسی.
- 📅 **تقویم شمسی** و ارقام فارسی در سراسر اپ.
- 📴 **کاملاً آفلاین:** بدون نیاز به اینترنت یا حساب کاربری.

## 🏗 معماری

ساختار لایه‌ای با **Riverpod** به‌عنوان واسط بین UI و داده:

```
features  →  providers  →  repositories  →  AppDatabase (sembast)
                                  ↑
                              domain (منطق خالص و قابل‌تست)
```

- **`lib/domain/`** — الگوریتم‌های خالص و بدون وابستگی به Flutter: `sm2` (زمان‌بندی)، `quiz`، `weak_cards`، `activity`، `answer_match`، `gamification`، `study_stats`.
- **`lib/data/`** — مدل‌ها، دیتابیس محلی (`sembast`، بدون codegen) و ریپازیتوری‌ها با استریم‌های زنده.
- **`lib/providers/`** — رجیستری مرکزی Riverpod و providerهای مشتق (شمارش سررسید، آمار، سطح و…).
- **`lib/features/`** — یک پوشه برای هر صفحه (خانه، دک‌ها، مرور، آزمون، آمار، تنظیمات).
- **`lib/core/`** — ابزارهای مشترک: فارسی‌سازی، نوتیفیکیشن، TTS، تم، و ویجت‌ها.

## 🗂 ساختار پروژه

</div>

```
lib/
├── main.dart              # نقطه‌ی شروع: باز کردن DB، seed، نوتیفیکیشن
├── app.dart               # ریشه‌ی اپ (تم، RTL، مسیریاب)
├── core/                  # فارسی‌سازی، نوتیفیکیشن، TTS، تم، ویجت‌ها
├── data/                  # مدل‌ها، دیتابیس (sembast)، ریپازیتوری‌ها، داده‌ی اولیه
├── domain/                # الگوریتم‌های خالص (SM-2، quiz، gamification، …)
├── providers/             # رجیستری Riverpod
├── features/              # صفحه‌ها: home, decks, review, quiz, stats, settings
└── router/                # مسیریابی go_router
test/                      # تست‌های واحدِ منطق دامین
```
