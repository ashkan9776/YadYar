
# طرح پیاده‌سازی سیستم Freemium یادیار

## خلاصه
اضافه کردن سیستم محدودیت رایگان + خرید پرو با SDK کافه‌بازار (`cafebazaar_flutter`). محدودیت‌ها: ۳ دسته، ۲ کتاب/دسته، ۵ دک/کتاب، ۵۰ کارت/دک.

---

## فایل‌های جدید (۵ فایل)

### 1. `lib/core/services/purchase_service.dart` — سرویس خرید کافه‌بازار
- کلاس `PurchaseService` با Singleton pattern
- استفاده از `CafebazaarFlutter.instance.inAppPurchase(PUBLIC_KEY)`
- متدها:
  - `init()` — راه‌اندازی اتصال به کافه‌بازار
  - `isPro()` — بررسی وضعیت پرو (اول از تنظیمات محلی، بعد از `getPurchasedProducts()`)
  - `purchasePremium()` — خرید محصول (productId: `'yadyar_premium'`)
  - `restorePurchase()` — بازیابی خرید قبلی
  - `dispose()` — قطع اتصال
- **نکته**: `PUBLIC_KEY` فعلاً placeholder — کاربر باید بعداً کلید واقعی رو جایگزین کنه
- مدیریت خطا: اگر بازار نصب نباشه یا خرید ناموفق باشه، بدون crash پیام مناسب نشون بده

### 2. `lib/core/services/freemium_service.dart` — مدیریت محدودیت‌ها
- کلاس `FreemiumLimits` با ثابت‌ها:
  ```dart
  static const int maxCategories = 3;
  static const int maxBooksPerCategory = 2;
  static const int maxDecksPerBook = 5;
  static const int maxCardsPerDeck = 50;
  ```
- کلاس `FreemiumService`:
  - `canCreateCategory(int currentCount, bool isPro)` → bool
  - `canCreateBook(int currentCount, bool isPro)` → bool
  - `canCreateDeck(int currentCount, bool isPro)` → bool
  - `canCreateCard(int currentCount, bool isPro)` → bool
  - `limitMessage(entity)` → پیام فارسی محدودیت (مثلاً: «نسخه رایگان حداکثر ۳ دسته‌بندی دارد»)

### 3. `lib/features/premium/premium_dialog.dart` — دیالوگ خرید (Upsell)
- ویجت `showPremiumDialog(BuildContext context, String reason)`
- دیالوگ زیبا با:
  - آیکون 👑 یا Icons.workspace_premium
  - عنوان: «نسخه حرفه‌ای یادیار»
  - لیست مزایا به فارسی با آیکون:
    - ✅ دسته‌بندی و کتاب نامحدود
    - ✅ حداکثر ۵۰ کارت به ازای هر دک
    - ✅ بدون تبلیغ
    - ✅ قابلیت‌های آینده (چالش روزانه، آمار پیشرفته و...)
  - دکمه «خرید از کافه‌بازار» (سبز/بنفش)
  - دکمه «بعداً» (خاکستری)
- اگر خرید موفق بود: ذخیره در AppSettings و بستن دیالوگ

### 4. `lib/features/premium/premium_badge.dart` — نشان پرو در AppBar
- ویجت `PremiumBadge` — آیکون کوچک 👑 در کنار عنوان AppBar صفحات اصلی
- نمایش فقط وقتی `isPro == true`

### 5. `lib/providers/purchase_provider.dart` — Providerهای خرید
- `purchaseServiceProvider` — Provider<PurchaseService>
- `isProProvider` — StateProvider<bool> (آیا کاربر پرو هست)
- `isProStreamProvider` — از settingsStreamProvider خوانده میشه + بررسی خرید بازار

## فایل‌های تغییرداده‌شده (۹ فایل)

### 6. `pubspec.yaml` — اضافه کردن SDK
```yaml
dependencies:
  cafebazaar_flutter: ^2.0.0
```

### 7. `lib/data/models/app_settings.dart` — اضافه کردن فیلد `isPro`
- فیلد جدید: `isPro` (bool, default `false`)
- آپدیت `copyWith()`, `toMap()`, `fromMap()`

### 8. `lib/providers/providers.dart` — اضافه کردن providerهای محدودیت
- اضافه کردن:
  - `isProProvider` — خواندن از `settingsProvider.isPro`
  - `categoryCountProvider` — `ref.watch(categoriesStreamProvider).value?.length ?? 0`
  - `bookCountProvider(int categoryId)` — شمارش کتاب‌های یک دسته
  - `deckCountProvider(int bookId)` — شمارش دک‌های یک کتاب
  - `cardsInDeckCountProvider(int deckId)` — شمارش کارت‌های یک دک

### 9. `lib/features/categories/categories_page.dart` — بررسی محدودیت دسته (خط ۴۶)
- `_NewItemTile` → تبدیل به `ConsumerWidget`
- در `onTap`: بررسی `categoryCount >= 3 && !isPro` → نمایش `showPremiumDialog`
- نمایش تعداد مصرف‌شده/حداکثر در کنار «+ دسته جدید» (مثلاً: «+ دسته جدید (۲/۳)»)

### 10. `lib/features/categories/category_detail_page.dart` — بررسی محدودیت کتاب (خط ۵۷)
- FAB `onPressed`: بررسی تعداد کتاب‌های این دسته ≥ ۲ && !isPro
- نمایش «+ کتاب جدید (۱/۲)» روی FAB

### 11. `lib/features/books/book_detail_page.dart` — بررسی محدودیت دک (خط ۴۵)
- FAB `onPressed`: بررسی تعداد دک‌های این کتاب ≥ ۵ && !isPro
- نمایش «+ دک جدید (۳/۵)» روی FAB

### 12. `lib/features/decks/deck_detail_page.dart` — بررسی محدودیت کارت (خط ۵۲)
- FAB `onPressed`: بررسی تعداد کارت‌های این دک ≥ ۵۰ && !isPro
- نمایش «کارت جدید (۴۲/۵۰)» روی FAB

### 13. `lib/features/settings/settings_page.dart` — اضافه کردن بخش پرو
- بخش جدید «نسخه حرفه‌ای» در بالای تنظیمات:
  - اگر پرو: «✅ نسخه حرفه‌ای فعال» + تاریخ فعال‌سازی
  - اگر رایگان: «🔄 ارتقا به نسخه حرفه‌ای» → `showPremiumDialog`
  - دکمه «بازیابی خرید» (Restore)

### 14. `lib/main.dart` — راه‌اندازی PurchaseService
- در `main()`: فراخوانی `PurchaseService.instance.init()` پس از `WidgetsFlutterBinding.ensureInitialized()`

## ترتیب پیاده‌سازی

1. **پاب‌خاص**: اضافه کردن `cafebazaar_flutter` به `pubspec.yaml` + `flutter pub get`
2. **مدل**: آپدیت `AppSettings` با فیلد `isPro`
3. **سرویس**: ساخت `PurchaseService` و `FreemiumService`
4. **دیالوگ**: ساخت `PremiumDialog` و `PremiumBadge`
5. **Providerها**: اضافه کردن providerهای جدید
6. **اعمال محدودیت**: تغییر ۴ صفحه (categories, category_detail, book_detail, deck_detail)
7. **تنظیمات**: اضافه کردن بخش پرو به settings_page
8. **راه‌اندازی**: آپدیت `main.dart`
9. **تست**: `flutter analyze` + `flutter build apk --debug`
